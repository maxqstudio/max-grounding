# MAX Grounding

MAX Grounding is a self-hostable, evidence-first grounding engine for LLMs and agents.

> Bootstrap status: repository initialized. Product implementation and governed documentation are established through tested pull requests.

## Goals

- live web retrieval with bounded search budgets;
- deterministic evidence extraction and provenance;
- hybrid retrieval and reranking;
- freshness, source-authority, and contradiction handling;
- claim-level citations and verification;
- REST and MCP interfaces;
- Linux, Windows, and macOS core-runtime support;
- multi-architecture Linux container images (`amd64` and `arm64`).
